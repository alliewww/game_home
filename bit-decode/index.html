🖥️ 遊戲說明

  • 電腦只看得懂 0 和 1，這叫做二進位。
  • 左邊的數字是「人類的語言」，你的工作是把它翻譯成 0 和 1 傳給電腦。
  • 每個開關代表一個數值（1、2、4、8、16…）。撥成 1 就是開，0 就是關。
  • 把開關加起來 = 左邊的數字，就翻譯成功！✅
  • 💡 例如數字 5：把「4」和「1」撥成 1，其他撥成 0。4＋1＝5，送出！
  • 🌟 小知識：電腦裡所有的東西——圖片、音樂、文字——都是 0 和 1 組成的！

🖥️ 遊び方

  • コンピュータが理解できるのは 0 と 1 だけ——それが二進数です。
  • 左の数字は「人間の言葉」。それを 0 と 1 に翻訳 してコンピュータに送りましょう。
  • 各スイッチは数値（1・2・4・8・16…）を表します。1 にするとオン、0 はオフ。
  • スイッチを合計すると左の数字になれば翻訳成功！✅
  • 💡 例：数字 5 なら「4」と「1」を 1 にして、残りを 0 に。4＋1＝5 で送信！
  • 🌟 豆知識：コンピュータの画像・音楽・文字はすべて 0 と 1 でできています！

🖥️ HOW TO

  • Computers only understand 0 and 1 — that's called binary.
  • The number on the left is in "human language." Your job: translate it into 0s and 1s for the computer.
  • Each switch stands for a value (1, 2, 4, 8, 16…). Flip to 1 = on, 0 = off.
  • When the switches add up to the number on the left — translation sent! ✅
  • 💡 Example: for 5, flip "4" and "1" to 1, keep the rest 0. 4+1=5, done!
  • 🌟 Fun fact: Every image, sound, and word in a computer is stored as 0s and 1s!
